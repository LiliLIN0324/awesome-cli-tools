# 深度页索引 / Deep-dive index

深度页是「读过就能上手」的单工具文档：安装、常用命令、配置、坑，以及和同类
工具的客观取舍。它比分类表格里那一行重得多，所以只给**确实需要**的工具写。

想新增？复制 [模板](../templates/tool.md)，先读
[CONTRIBUTING.md](../../CONTRIBUTING.md) 里「新增一个深度页」的要求。
